# TerraQuest Wildlife Conservation Park

TerraQuest is a full-stack promotional website for a fictional wildlife conservation park.

The website was developed as part of the QHO431 Web Technologies assessment. It uses Node.js, Express, EJS, JavaScript and SQLite.

## Project purpose

The purpose of the website is to promote the park and provide useful information for visitors.

The website includes information about:

* habitats
* wildlife experiences
* events
* frequently asked questions
* opening hours
* conservation activities
* contact enquiries

## Main features

The project includes the following features:

* database-driven habitats, experiences, events and FAQs
* individual pages for habitats and events
* AJAX filters for experiences and events
* an AJAX site search
* a contact form that stores messages in SQLite
* an interactive JavaScript wildlife activity
* responsive layouts for desktop, tablet and mobile
* a mobile navigation menu
* a custom 404 page
* current, past and upcoming event statuses

## Technologies used

* HTML
* CSS
* JavaScript
* Node.js
* Express
* EJS
* SQLite

## Installation

Open a terminal in the project folder and install the required packages:

```bash
npm install
```

## Running the website

Start the application with:

```bash
npm start
```

The website will run at:

```text
http://localhost:5000
```

The application can also be started with:

```bash
node index.mjs
```

## Database

The SQLite database stores the main website content, including:

* habitats
* experiences
* event categories
* events
* FAQs
* contact messages

The database is located inside the `database` folder.
